# Introduction

## What is Wazuh?

Wazuh is an open-source security platform used for monitoring endpoints, collecting logs, detecting threats, and responding to security incidents. It helps security teams analyze logs and identify suspicious activities from different systems.

It is widely used in Security Operations Centers (SOCs) to monitor and protect an organization's IT infrastructure.

---

## Why I Built This Lab

I created this SOC Home Lab to gain hands-on experience with Wazuh and understand how security monitoring works in a real environment.

The objectives of this project are:

- Learn the basics of Wazuh
- Configure a Windows agent
- Integrate Sysmon with Wazuh
- Generate and analyze security logs
- Learn Regex
- Create custom decoders

---

## What is a SOC?

A Security Operations Center (SOC) is a team responsible for monitoring, detecting, investigating, and responding to cybersecurity threats.

SOC analysts continuously monitor security alerts to identify suspicious activities and protect systems from attacks.
